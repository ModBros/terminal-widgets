# 1.1.0

- Requires MoBro with dashboard SDK 1.5 or newer.
- Settings only show when they have an effect, e.g. the threshold settings only in threshold color mode, and the keys of the Key Bar only up to the number of keys.
- Themes, styles, color modes, alignments and sort orders are picked with buttons, thresholds and the number of keys with sliders.
- Related settings such as min and max value or font and font size sit side by side.
- Existing dashboards keep all their settings.

# 1.0.1

- Fixed box drawing characters overflowing the panel border on Android.

# 1.0.0

- Initial release with the Meter, Meter Grid, Summary, Graph, Panel, Table, Readout and Key Bar widgets.
- Color (htop, btop) and Monochrome (top) themes for every widget.
